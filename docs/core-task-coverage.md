## Release gate

`python3 scripts/check_core_coverage.py` checks inventory and evidence structure. `--require-accepted` additionally fails while any task is unaccepted. The inventory check does not execute or independently certify the linked source. Current unit/fault/process tests do not substitute for native UI, real provider, hostile-process, cross-platform or VM/power-loss qualification.

The accepted status requires an exact tested commit, structured successful task-specific report, and an actual linked acceptance review; no task is marked accepted by this update.
